## ❤️ Bienvenido a Zofo Extremo

**Zofo Extremo** es un modpack para **Minecraft 1.21.1** basado en **Fabric**, creado para ofrecer una experiencia diferente, divertida y extrema. 

El modpack reúne diferentes mods, configuraciones y mejoras de rendimiento para crear una experiencia de supervivencia completa, desafiante y fluida en Minecraft.

> ⚠️ **IMPORTANTE:** Zofo Extremo utiliza **Minecraft 1.21.1 + Fabric**.  
> No utilices otras versiones de Minecraft o loaders diferentes (como Forge o NeoForge).

### 🗂️ Método 2: Instalación Normal (Launcher Oficial)

Si prefieres instalar **Zofo Extremo** manualmente en el launcher clásico de Minecraft:

1. **Descarga el archivo:** Descarga **[`minecraft.zip`](https://github.com/tusmocraft/zofoextremo/releases/download/relase/minecraft.zip)**.
2. **Descomprime el archivo:** Al descomprimirlo verás carpetas como `mods`, `config`, etc.  
   > ⚠️ **IMPORTANTE:** El ZIP no contiene una carpeta llamada "minecraft". Los archivos ya están sueltos.
3. **Abre tu directorio de Minecraft:** Ve a tu carpeta `.minecraft` (puedes buscar `%appdata%/.minecraft` en Windows).
4. **Copia los archivos:** Pega **todo** el contenido extraído directamente dentro de la carpeta `.minecraft`.  
   ❌ *Incorrecto:* `.minecraft/minecraft/mods`  
   ✅ *Correcto:* `.minecraft/mods`
5. **Configura tu Launcher:** Asegúrate de tener instalado y seleccionado el perfil de **Fabric para la versión 1.21.1**. ¡Inicia el juego y listo!

### 🟢 Método 3: Modrinth App

1. Descarga el archivo **[`Zofo.Extremo.modrinth.mrpack`](https://github.com/tusmocraft/zofoextremo/releases/download/relase/Zofo.Extremo.-.modrith.mrpack)**.
2. Abre la aplicación de **Modrinth**.
3. Haz clic en el botón **"+" (Add Instance)** o "Crear Instancia".
4. Selecciona la opción **"From File"** (Desde archivo) o "Import".
5. Busca y selecciona el archivo `.mrpack` que acabas de descargar. Modrinth instalará todo automáticamente.

---

### 🟠 Método 4: CurseForge App

1. Descarga el archivo **[`Zofo.Extremo.curseforge.zip`](https://github.com/tusmocraft/zofoextremo/releases/download/relase/Zofo.Extremo.-.curse.zip)**.
2. Abre la aplicación de **CurseForge** y ve a la sección de Minecraft.
3. Haz clic en **"Create Custom Profile"** (Crear perfil personalizado) en la parte superior derecha.
4. Haz clic en el enlace de texto que dice **"Import"** (Importar) que aparece en la ventana emergente.
5. Selecciona el `.zip` de CurseForge que descargaste. La app creará el perfil con todos los mods listos para jugar.
